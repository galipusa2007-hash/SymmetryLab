# SymmetryLab

Интерактивная лаборатория симметрии молекул (TiO₂, аллен C₃H₄, боразин B₃N₃H₆).

## Запуск на Mac

Откройте **SymmetryLab** в PyCharm и используйте Terminal в корне проекта:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run main.py
```

В браузере откроется локальный адрес, обычно `http://localhost:8501`.

## Как пользоваться

1. Выберите молекулу, затем операцию симметрии.
2. В 3D-поле поверните систему мышью, сохраняя видимость осей X, Y, Z.
3. Меняйте **Ход преобразования**: ракурс и масштаб не должны сбрасываться.
4. Используйте **🔍 +** и **🔍 −** для приближения и удаления всей геометрической модели (атомы — объёмные сферы в ангстремах), **↺ Ракурс** для восстановления вида, **⛶ Во весь экран** для увеличения области просмотра.
5. Разверните пояснения к операции и объяснение начала координат.

Для операций, которые оставляют *все индивидуальные атомы* на местах (E, σᵥ(xz) у TiO₂, σₕ(xy) у боразина), ползунок не отображается.

## Архитектура

| Файл / папка | Назначение |
|---|---|
| `main.py` | Страница, каталог операций, химические пояснения |
| `models/molecule_data.py` | Атомы, связи, координаты и группы |
| `symmetry/operations.py` | Матрицы всех операций |
| `symmetry/progression.py` | Этапы преобразования |
| `symmetry/validator.py` | Проверка совпадения атомов |
| `visualization/interactive_viewer.py` | Передаёт геометрию 3D-компоненту |
| `visualization/assets/viewer.html` | Собственные элементы управления и отрисовка Plotly.js в браузере |
| `content/descriptions.py` | Математические и химические пояснения |
| `tests/` | Автоматические проверки |

**Важно:** ползунок расположен внутри браузерного 3D-компонента, поэтому не вызывает нового выполнения Streamlit для каждого положения. Положение камеры сохраняется при изменении хода операции. При переключении молекулы или операции 3D-компонент создаётся заново с исходным ракурсом. Это намеренное поведение текущей версии.

3D-компонент загружает библиотеку Plotly.js с CDN; для первого открытия 3D-графика необходимо подключение к интернету. Если оно недоступно, появится сообщение о невозможности загрузки модуля.

Отражения и инверсии показаны как *условные геометрические интерполяции*, а не реальная траектория движения атомов. Кнопка «Во весь экран» использует браузерный Fullscreen API и может быть ограничена правилами iframe в некоторых браузерах.

## Тесты

```bash
python -m unittest discover -s tests -v
```

## Постоянная ссылка

Для публикации загрузите содержимое этой папки в GitHub-репозиторий и подключите его на https://share.streamlit.io. В качестве entrypoint укажите `main.py`. Репозиторий и папка проекта теперь называются **SymmetryLab**; при обновлениях меняйте классы внутри существующего проекта.

Не публикуйте `.venv`, `.env` и секретные ключи.

## Голубой интерфейс и материалы РГР

Светлое оформление задаётся `content/site_theme.css`, темой Streamlit в `.streamlit/config.toml` и оформлением трёхмерной сцены в `visualization/assets/viewer.html`.

Контрастные пространственные оси: **X — терракотовая**, **Y — тёмно-бирюзовая**, **Z — синяя**.

Во вкладке «Материалы РГР» представлены две части: теоретическая справка в текстовом представлении (`content/part1_notes.md`) и полный оригинальный документ «Часть 2.docx» с постраничным просмотром изображений в `resources/part2` и скачиванием. Первая часть пока представлена структурированным текстом, а не точной копией исходного DOCX; для добавления оригинала достаточно поместить его в `resources/` и доработать `content/research_tab.py`.
