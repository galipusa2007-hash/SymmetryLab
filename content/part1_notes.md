# Часть 1. Теоретическая справка

## 1. Основные понятия

**Элемент симметрии** — геометрический объект (точка, прямая, плоскость), относительно которого осуществляется операция, переводящая молекулу в неотличимое от исходного положение.

**Операция симметрии** — само преобразование координат: тождество, вращение, отражение, инверсия либо поворотно-зеркальная операция.

**Точечная группа** — полный набор операций симметрии, оставляющих хотя бы одну точку неподвижной и удовлетворяющих групповым аксиомам: замкнутость, ассоциативность, наличие нейтрального и обратных элементов. Порядок группы — количество её различных операций.

## 2. Операции симметрии

| Обозначение | Смысл | Характерный пример |
|---|---|---|
| E | Тождество | Каждый атом остаётся на месте |
| Cₙ | Поворот на 360°/n | C₂ — поворот на 180° |
| σ | Отражение относительно плоскости | σ(xz): (x,y,z) → (x,−y,z) |
| i | Инверсия относительно точки | (x,y,z) → (−x,−y,−z) |
| Sₙ | Поворот на 360°/n, затем отражение в перпендикулярной плоскости | S₄ для аллена |

Повторное вращение **Cₙᵏ** означает поворот на `k·360°/n`. Для C₃ получаем C₃ (120°), C₃² (240°), C₃³ = E (360°).

## 3. Плоскости симметрии

- **σᵥ** — вертикальная плоскость, содержащая главную ось вращения.
- **σₕ** — горизонтальная плоскость, перпендикулярная главной оси.
- **σd** — диагональная плоскость, содержащая главную ось и биссектрису угла между соседними осями C₂, перпендикулярными главной.

## 4. Матричная форма

Для поворота вокруг Z на угол φ:

`Rz(φ) = [[cosφ, −sinφ, 0], [sinφ, cosφ, 0], [0, 0, 1]]`

Отражение в XY:

`σxy = diag(1, 1, −1)`

Инверсия:

`i = diag(−1, −1, −1)`

Поворотно-зеркальная операция: `Sₙ = σₕ · Cₙ` (сначала поворот, затем отражение).

## 5. Определение точечной группы

1. Проверить, является ли молекула линейной.
2. Найти собственные оси вращения Cₙ и выбрать ось с наибольшим n.
3. Определить наличие перпендикулярных осей C₂.
4. Проверить горизонтальные, вертикальные и диагональные плоскости отражения.
5. Проверить наличие центра инверсии и поворотно-зеркальных операций.
6. Назвать группу по совокупности элементов и перечислить все операции.

## 6. Свойства операций

`Cₙⁿ = E`, `σ² = E`, `i² = E`, `S₁ = σ`, `S₂ = i`. Ассоциативность следует из ассоциативности композиции преобразований, замкнутость и наличие обратных операций проверяются по матрицам.
