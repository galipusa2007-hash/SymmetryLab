# 3. Программная визуализация операций симметрии

## 3.1. Цель

Разработано интерактивное веб-приложение Molecular Symmetry Lab на Python с использованием NumPy, Plotly и Streamlit. Оно отображает три выбранные структуры — изолированную молекулу TiO₂, аллен C₃H₄ и боразин B₃N₃H₆ — и выполняет матричные преобразования координат, соответствующие операциям точечных групп C₂v, D₂d и D₃h.

## 3.2. Системы координат

Система координат закреплена относительно исходной молекулы. Для TiO₂ начало координат помещено в Ti, ось Z направлена по биссектрисе O–Ti–O, плоскость молекулы — XZ. Для аллена начало помещено в центральный C, ось Z совпадает с цепью C=C=C, концевые группы CH₂ лежат в перпендикулярных плоскостях XZ и YZ. Для боразина начало координат находится в центре кольца, плоскость кольца — XY, главная ось C₃ направлена вдоль Z. Это **удобный выбор системы отсчёта для матриц**, но не утверждение о наличии у молекулы центра инверсии.

## 3.3. Математическая реализация

Координаты атомов хранятся в массиве N×3 (Å). Операция описывается ортогональной матрицей 3×3; для каждой позиции-столбца r вычисляется r′ = M r. Для поворотов используется матрица Родрига, для отражения относительно плоскости с нормалью n — M = I − 2nnᵀ, для поворотно-зеркальной операции — произведение M = M_σ R. Для S₄ (аллен) и S₃ (боразин) интерфейс отдельно показывает этап вращения и этап отражения.

В точках между начальным и конечным положениями визуализация отражений выполняется с помощью линейной интерполяции; она не изображает физическое движение атомов. Для обычных вращений на промежуточных этапах вычисляется матрица поворота на текущий угол.

## 3.4. Пользовательский интерфейс

На странице доступны выбор молекулы, каталог операций группы, одна интерактивная 3D-сцена, цветные оси X, Y, Z, ползунок выполнения операции, отображение элемента симметрии и опциональная полупрозрачная исходная модель. Для каждой структуры предусмотрено объяснение, почему выбранное начало координат удобно. Математическая матрица, таблица координат и химические комментарии скрыты в раскрывающихся разделах, чтобы не перегружать главный экран.

## 3.5. Проверка корректности

Преобразованные координаты сравниваются с исходными в **фиксированной системе отсчёта**, без оптимального вращательного наложения. Для каждого химического элемента отдельно проверяется возможность взаимно-однозначной перестановки равных атомов в пределах допуска 10⁻⁵ Å. Дополнительно тестируются ортогональность матриц, уникальность операций, замкнутость группы и существование обратной операции. Всего проверяются 4 + 8 + 12 = 24 операции.

## 3.6. Ограничения и дальнейшее развитие

Геометрии идеализированы и служат для исследования симметрии; это не результаты оптимизации геометрии. В качестве следующего расширения предполагается загрузка пользовательских молекул и анализ их операций симметрии, но эта функция пока не реализована. Публикация через Streamlit Community Cloud даст общий веб-адрес для студентов и преподавателя.
